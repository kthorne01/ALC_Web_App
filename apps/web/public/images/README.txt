CHURCH PHOTOS — Where to Add Images
=====================================

hero/
  hero-bg.jpg         Main homepage hero background (recommended: 1920x1080, dark/dramatic)
  hero-bg-mobile.jpg  Mobile version (optional, 768x1024)

team/
  pastor.jpg          Lead pastor photo (square crop works best)
  elder-1.jpg         Elder/leader photo
  elder-2.jpg         Elder/leader photo
  (add more as needed, name by person)

church/
  building.jpg        Exterior photo of the church building
  congregation.jpg    Congregation during service (wide shot)
  worship.jpg         Worship service photo
  community.jpg       Community/fellowship event photo

NOTES:
- Keep file sizes under 500KB for fast load times
- Use JPG for photos, PNG for logos/graphics
- Recommended dimensions: 1200x800 minimum for section backgrounds
- Hero image: dark/moody photos work best with the site's aesthetic
